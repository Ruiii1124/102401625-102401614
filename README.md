## 一、项目简介

一个面向校园学生的失物招领 Web 应用，帮助同学们集中发布和查看寻物、招领信息，并通过物品名称等关键词快速搜索。主要流程为：

**发布信息 → 浏览/搜索 → 查看详情 → 联系发布者 → 更新状态**

技术栈：纯 HTML + CSS + 原生 JavaScript，数据存储在浏览器 `localStorage` 中，无需后端服务。

## 三、使用说明

### 3.1 运行网页

1. 用 **Chrome 或 Edge 浏览器**打开项目根目录下的 `index.html`。
2. 也可以使用 VS Code 的 **Live Server** 插件：右键 `index.html`，选择“Open with Live Server”。
3. 无需安装任何依赖即可运行网页，`localStorage` 会自动保存数据。

### 3.2 功能操作指南

| 操作 | 步骤 |
|------|------|
| 浏览信息 | 打开首页，默认显示最新信息，点击卡片查看详情 |
| 筛选类型 | 首页点击“最新信息 / 寻物启事 / 招领信息”切换 |
| 分类快捷搜索 | 首页点击“校园卡 / 钥匙 / 雨伞 / 电子产品”图标 |
| 发布信息 | 底部导航“发布”→ 选择寻物/招领 → 填写表单 → 确认发布 |
| 搜索物品 | 首页搜索框或底部“搜索”→ 输入关键词 → 查看搜索结果 |
| 查看详情 | 点击任意信息卡片，进入详情页 |
| 联系发布者 | 详情页点击“联系发布者”→ 查看 QQ 号 → 一键复制 |
| 更新状态 | 底部“我的”→ 进行中 → 标记为已找回/已归还 |
| 查看已完成 | 底部“我的”→ 切换到“已完成”标签 |

### 3.3 运行单元测试

**前置条件**：已安装 Node.js（LTS 版本）。

```bash
# 安装依赖
npm install

# 运行测试
npm test
```

期望输出：`12 passing`，表示 12 个测试用例全部通过。

> 注意：如果 PowerShell 提示“禁止运行脚本”，请在 PowerShell 中运行 `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`，或改用 CMD 执行命令。

## 五、附加特点

1. **一键复制联系方式**：联系页点击按钮即可复制 QQ 号，避免手动输入出错。
2. **搜索历史记录**：搜索页自动保存最近 5 条搜索关键词，点击可快速重新搜索。
3. **状态闭环**：发布者标记“已找回/已归还”后，首页、搜索结果、详情页同步显示“已解决”标签，详情页联系按钮自动禁用。
4. **空状态友好提示**：无数据、无搜索结果时给出明确提示，不会显示空白页面。
5. **分类图标**：不同物品分类显示不同 emoji 图标，提升可读性。

## 六、浏览器兼容性

- 推荐使用 **Chrome** 或 **Edge**（基于 Chromium 内核，渲染效果一致）。
- 使用 `localStorage` 存储数据，不同浏览器数据不互通，清除浏览器数据会清空已发布信息。
